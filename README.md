## 📖 About

🔹 **REPENTOGON** is a powerful tool built to help you expand The Binding of Isaac modding capabilities with REPENTOGON's extended API and game hooks. REPENTOGON unlocks previously inaccessible game functions, enabling mods with capabilities impossible through the vanilla Lua API.

🔸 Whether you're a seasoned professional or just getting started, **REPENTOGON** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Binding of Isaac modding workflow. Download now and get started in minutes. 🚀
